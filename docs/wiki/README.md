# VE Ops

VE Ops automates the mundane parts of running an Amateur Radio Volunteer Examiner session:
pulling registrations from ExamTools, scheduling the Zoom meeting and Discord event, collecting the
exam fee, emailing candidates, watching the FCC for grants, and tracking what has been filed with
the VEC.

**This wiki is the user manual.** It answers "how do I do this" for the people who use the app. It
does not explain how the code works — that lives in [`/docs`](https://github.com/MikeWills/VeOps/tree/main/docs)
in the repository, next to the code it describes.
